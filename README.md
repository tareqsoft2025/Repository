# نظام الحضور والانصراف

تطبيق ويب ثابت (HTML/CSS/JS) بدون خادم. البيانات في قاعدة SQLite حقيقية تعمل داخل المتصفح (مكتبة [sql.js](https://github.com/sql-js/sql.js) المضمّنة في `js/vendor`) وتُحفظ في IndexedDB.

## التشغيل
افتح `login.html` في المتصفح، أو شغّل خادماً محلياً: `python3 -m http.server`.

## الحسابات التجريبية
- مدير: `admin` / `admin123`
- موظف: `ahmed` / `123456`

## الميزات
- تسجيل حضور وانصراف مرة واحدة يومياً، مع احتساب التأخير (بعد 09:00) وساعات العمل.
- سجل شهري وإحصائيات للموظف.
- المدير: عرض سجل كل الموظفين حسب اليوم، تصدير CSV، إضافة مستخدمين.
- المدير: تصدير قاعدة البيانات كملف `.sqlite` واستيرادها (نسخ احتياطي أو نقل بين الأجهزة).
- ترحيل تلقائي لبيانات النسخة القديمة (localStorage) عند أول تشغيل.

## ملاحظة
القاعدة محلية لكل متصفح؛ لمشاركة البيانات بين الأجهزة استخدم التصدير/الاستيراد. كلمات المرور محفوظة كنص عادي في القاعدة لأغراض العرض فقط. للاستخدام الفعلي يلزم خادم وقاعدة بيانات ومصادقة آمنة.
