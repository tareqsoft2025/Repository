# نظام شؤون الموظفين

تطبيق ويب ثابت (HTML/CSS/JS) بدون خادم. البيانات في قاعدة SQLite حقيقية تعمل داخل المتصفح (مكتبة [sql.js](https://github.com/sql-js/sql.js) المضمّنة في `js/vendor`) وتُحفظ في IndexedDB.

## التشغيل
افتح `login.html` في المتصفح، أو شغّل خادماً محلياً: `python3 -m http.server`.

## الحسابات التجريبية
- مدير: `admin` / `admin123`
- موظف: `ahmed` / `123456`

## الوحدات
- **شؤون الموظفين** (الوحدة الأساسية): ملف لكل موظف يضم البيانات الشخصية وبيانات الاتصال والبيانات الوظيفية وجهة اتصال الطوارئ.
- **العقود**: عقود الموظفين مع الحالات والتنبيه بقرب الانتهاء والتجديد.
- **الحضور والانصراف**: تسجيل الدوام والتقارير الشهرية.

## الميزات
**الربط بين الوحدات**
- ملف الموظف يُربط بحساب دخوله، فيظهر في الملف ملخص حضور الشهر (الحضور والغياب والتأخير والساعات) ويظهر مسمى الموظف وقسمه في الشريط العلوي.
- حساب واحد لكل موظف، ولا يُربط حساب بملفين.

**صلاحية «مسؤول موارد بشرية»**
- يمنحها المدير من تبويب «الحسابات» لأي مستخدم دون جعله مديراً: تفتح تبويبَي «شؤون الموظفين» و«العقود» فقط.
- لا يصل مسؤول الموارد إلى التقارير أو الحسابات أو الإعدادات.
- لا يعدّل ملفه الشخصي أو عقده بنفسه (فصل المسؤوليات)، ولا يربط حسابه بملف.

**العقود (موارد بشرية)**
- أنواع: دائم، محدد المدة، تجريبي، موسمي، دوام جزئي. الدائم بلا تاريخ انتهاء وغيره يتطلب تاريخ انتهاء.
- راتب أساسي وبدلات مع إجمالي فوري، ورقم عقد تلقائي (`CNT-0001`).
- حالات محسوبة: ساري، ينتهي قريباً (خلال 30 يوماً)، لم يبدأ، منتهي، ملغى.
- منع تداخل عقدين ساريين لنفس الموظف، وتجديد بنقرة (يبدأ بعد انتهاء العقد السابق بنفس المدة).
- بحث وتصفية بالحالة وتصدير CSV، وحذف الموظف يحذف عقوده.

**شؤون الموظفين**
- إضافة بيانات الموظف وتعديلها وحذفها: الاسم، الهوية، الجنس، تاريخ الميلاد، الجنسية، الحالة الاجتماعية، الهاتف، البريد، العنوان، رقم الموظف (تلقائي)، القسم، المسمى الوظيفي، نوع التوظيف، تاريخ التعيين، الراتب، الحالة، جهة الطوارئ، ملاحظات.
- تحقق من البيانات: الاسم، البريد، الهاتف، التواريخ، الراتب، وعدم تكرار رقم الموظف أو الهوية.
- بحث (بالاسم أو الرقم أو الهوية أو الهاتف) وتصفية بالحالة والقسم، وبطاقات إحصاء، وتصدير CSV.
- القسم والمسمى الوظيفي يقترحان القيم المستخدمة سابقاً.

**الموظف**
- تسجيل حضور وانصراف مرة واحدة يومياً، مع احتساب التأخير وساعات العمل.
- سجل شهري وإحصائيات ورسم بياني لساعات العمل اليومية.
- تغيير كلمة المرور.

**المدير**
- الحضور اليومي لكل الموظفين، مع إضافة سجل يدوي وتعديله وحذفه، وتصدير CSV.
- تقرير شهري (أيام الدوام، الحضور، الغياب، التأخير، الساعات) مع طباعة وتصدير CSV.
- إدارة الموظفين: إضافة، تعطيل/تفعيل، إعادة تعيين كلمة المرور (مع حماية آخر مدير فعّال).
- منح أو سحب **صلاحية تعديل الحضور والانصراف** لأي موظف (مثل الموارد البشرية) دون جعله مديراً.
- إعدادات الدوام: بداية ونهاية الدوام، مهلة التأخير، أيام الإجازة الأسبوعية.
- تصدير قاعدة البيانات كملف `.sqlite` واستيرادها (نسخ احتياطي أو نقل بين الأجهزة).

**صلاحية تعديل الحضور**
- من يملكها يرى تبويب «الحضور اليومي» فقط، ويضيف السجلات ويعدّلها ويحذفها لغيره.
- لا يستطيع تعديل سجلاته الشخصية (فصل المسؤوليات)، ولا يصل إلى التقارير أو الموظفين أو الإعدادات.
- كل سجل معدّل تظهر عليه علامة «معدّل» مع اسم من عدّله ووقت التعديل، ويراها الموظف صاحب السجل.

**الأمان والبيانات**
- كلمات المرور مشفّرة بـ PBKDF2-SHA256 مع ملح عشوائي، وترقية تلقائية لكلمات المرور القديمة عند أول دخول.
- ترقية تلقائية لمخطط القاعدة وترحيل بيانات النسخ القديمة.

## ملاحظة
القاعدة محلية لكل متصفح؛ لمشاركة البيانات بين الأجهزة استخدم التصدير/الاستيراد. التشفير يعمل على المتصفح فقط؛ لاستخدام فعلي متعدد الأجهزة يلزم خادم ومصادقة آمنة. للاستخدام الفعلي يلزم خادم وقاعدة بيانات ومصادقة آمنة.
