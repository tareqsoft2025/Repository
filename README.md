# نظام الحضور والانصراف

تطبيق ويب ثابت (HTML/CSS/JS) بدون خادم، تُحفظ البيانات في `localStorage` المتصفح.

## التشغيل
افتح `login.html` في المتصفح، أو شغّل خادماً محلياً: `python3 -m http.server`.

## الحسابات التجريبية
- مدير: `admin` / `admin123`
- موظف: `ahmed` / `123456`

## الميزات
- تسجيل حضور وانصراف مرة واحدة يومياً، مع احتساب التأخير (بعد 09:00) وساعات العمل.
- سجل شهري وإحصائيات للموظف.
- المدير: عرض سجل كل الموظفين حسب اليوم، تصدير CSV، إضافة مستخدمين.

## ملاحظة
كلمات المرور محفوظة كنص عادي في المتصفح لأغراض العرض فقط. للاستخدام الفعلي يلزم خادم وقاعدة بيانات ومصادقة آمنة.
