# خادم المزامنة — نسخة PHP (للاستضافات المشتركة)

نفس واجهة نسخة Node بالضبط، لكنها تعمل على أي استضافة **PHP 7.4+** مع **SQLite** (`pdo_sqlite`، متوفر عادة). لا تحتاج Node ولا SSH.

## التركيب (دقيقتان)
1. ارفع محتويات المجلد إلى مجلد على موقعك، مثل `public_html/hr` (ملفات: `index.php` و`.htaccess` و`config.php`). **انتبه:** قد يُرفع `.htaccess` باسم `download`؛ أعد تسميته إلى `.htaccess` (نسخة احتياطية باسم `htaccess.txt`). وإن تعذّر ذلك فاستخدم العنوان `https://موقعك/hr/index.php` ولا يلزم `.htaccess`.
2. افتح `config.php` (في الحزمة نسخة قالب) وغيّر `HR_SETUP_KEY` إلى مفتاح **عشوائي من 16 حرفاً على الأقل** (مثلاً من مدير كلمات المرور). **احفظه** ولا تنشره ولا ترفع `config.php` إلى GitHub أو تصوّره: من يعرفه قبل التهيئة يستطيع تهيئة الخادم ببياناته هو.
3. افتح `https://موقعك/hr/api/health` فيجب أن ترى `{"ok":true,"serverId":"...","initialized":false}`.
   - رسالة «غيّر HR_SETUP_KEY»: لم يُعدَّل المفتاح بعد.
   - خطأ 500 أو صفحة بيضاء: ارفع `check.php` بجانب `index.php` وافتحه؛ يعرض ما ينقص (إصدار PHP، SQLite، الصلاحيات) وزره الأخير يُظهر الخطأ الفعلي. **احذفه بعد الانتهاء.**
   - خطأ 404: الاستضافة لا تدعم `.htaccess`/mod_rewrite؛ أخبرني بنوع الخادم.
   - «تعذّر فتح قاعدة SQLite»: فعّل `pdo_sqlite` من إعدادات PHP.
4. **عنوان الخادم للنظام والتطبيق:** `https://موقعك/hr` (دون `/api`).

## الربط (مرة واحدة)
من النظام بحساب المدير على الجهاز الذي فيه البيانات: **الإعدادات ← الخادم المركزي ← رفع بيانات هذا الجهاز** (مفتاح التهيئة = `HR_SETUP_KEY`). بعدها يسجّل أي جهاز أو تطبيق «بصمة» الدخول بحسابه فتتزامن البيانات.

## الأمان
- قاعدة البيانات تُحفظ تلقائياً **خارج** `public_html` (في مجلد المستخدم `hr-data`) وباسم غير قابل للتخمين؛ وإن تعذّر ذلك تُحفظ في `data/` محمية بـ `.htaccess`. يمكنك تحديد المسار بـ `HR_DATA_DIR` في `config.php`.
- كلمات المرور مشفّرة PBKDF2، والصلاحيات تُفرض على الخادم، والحدّ 8 محاولات دخول / 10 دقائق، والجلسات 30 يوماً.
- **النسخ الاحتياطي:** انسخ ملف `hr-*.sqlite` من مجلد البيانات دورياً.
