# خادم المزامنة المركزي

قاعدة بيانات واحدة يشترك فيها **النظام (المتصفح)** وتطبيق **بصمة** على كل الأجهزة. بلا اعتماديات: Node 22.5+ فقط (يستخدم `node:sqlite`).

## التشغيل
```bash
cd server
SETUP_KEY=مفتاح-سري-طويل DATA_DIR=./data PORT=8080 node server.js
```
أو Docker: `docker build -t hr-sync server && docker run -d -p 8080:8080 -v hr-data:/data -e SETUP_KEY=... hr-sync`.
يجب وضعه خلف **HTTPS** (Render / Fly / Railway / Nginx + Let's Encrypt)، فمتصفح النظام على GitHub Pages لا يتصل بعنوان http. احفظ `DATA_DIR` على قرص دائم.

## الربط (مرة واحدة)
1. شغّل الخادم وانسخ مفتاح التهيئة (من متغير `SETUP_KEY` أو سجل التشغيل).
2. ضع عنوان الخادم في `js/config.js` (`window.HR_SERVER = 'https://...'`) وانشره، أو أدخله من الإعدادات.
3. من جهاز المدير الذي فيه البيانات: **الإعدادات ← الخادم المركزي ← رفع بيانات هذا الجهاز** وأدخل مفتاح التهيئة.
4. أي جهاز آخر: يسجّل الدخول بحسابه فتُحمَّل بياناته تلقائياً. تطبيق بصمة: يدخل بالحساب نفسه (يلزم عنوان الخادم في شاشة الدخول إن لم يُضبط في `config.js` وقت البناء).

## ما يحمله الخادم
- نسخة صفوف كل الجداول (مزامنة بمؤشر تسلسلي)، وكلمات المرور مشفّرة PBKDF2 كما في المتصفح.
- صلاحيات على الخادم: المدير كل شيء؛ الموارد البشرية ملفات الموظفين والعقود (دون الحسابات الإدارية)؛ محرر الحضور سجلات الحضور؛ الموظف سجلاته وعقده فقط.
- واجهة التطبيق: `POST /api/m/punch` تسجيل حضور/انصراف مع الموقع (مرة واحدة لكل `clientId`)، و`GET /api/m/me` بيانات اليوم والسجل.
- الحدّ من محاولات الدخول (8 محاولات / 10 دقائق)، وجلسات 30 يوماً.

## النسخ الاحتياطي
انسخ `DATA_DIR/hr.sqlite` دورياً. وفي حال فقدانه يمكن رفع بيانات جهاز المدير من جديد بالخطوة 3.
