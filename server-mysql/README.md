# خادم MySQL المركزي — نظام شؤون الموظفين

نسخة تجريبية لتجهيز خادم مركزي يستخدم MySQL/MariaDB مع واجهات API متوافقة مع المزامنة الحالية. لا تستخدمها مع بيانات الموظفين الحقيقية قبل اختبارها على نسخة احتياطية.

## قبل النشر
1. أنشئ قاعدة MySQL ومستخدمًا مخصصًا من لوحة الاستضافة.
2. انسخ `config.sample.php` إلى `config.php` على الخادم فقط، ثم أدخل بيانات الاتصال ومفتاح تهيئة عشوائيًا قويًا.
3. ارفع الملفات إلى مجلد الخادم واستخدم HTTPS.
4. اختبر `/api/health` أولاً، ثم اربط جهازًا تجريبيًا وارفع نسخة بيانات احتياطية.

لا ترفع `config.php` أو كلمات مرور MySQL أو بيانات الموظفين إلى GitHub.
